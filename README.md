# دیدبان CRM — نسخه حرفه‌ای پروژه Django

این پروژه نسخه بازطراحی‌شده و تکمیل‌شده `crm_project` است؛ یک سامانه راست‌چین برای مدیریت مشتریان، پروژه‌های اجرایی و پیگیری‌های فروش. کد عمداً با **Function-Based View** و وابستگی حداقلی نوشته شده تا هم برای استفاده واقعی مناسب باشد و هم بتوانید مسیر اجرای هر درخواست را قدم‌به‌قدم یاد بگیرید.

## قابلیت‌های اصلی

- ورود و خروج امن با سیستم احراز هویت Django
- جداسازی کامل داده کاربران؛ هر کاربر فقط مشتریان، پروژه‌ها و پیگیری‌های خودش را می‌بیند
- ثبت، مشاهده، ویرایش و حذف مشتری با کنترل شماره تکراری
- نرمال‌سازی شماره‌های فارسی/عربی به ارقام انگلیسی
- مدیریت قیف فروش با وضعیت‌های جدید، تماس‌شده، مذاکره، تبدیل‌شده و ازدست‌رفته
- مدیریت پروژه، بودجه، هزینه، سود، حاشیه سود، درصد پیشرفت و سررسید
- جلوگیری از حذف تصادفی مشتری دارای پروژه
- برنامه پیگیری تماس، ایمیل، جلسه و بازدید با اولویت و تشخیص کار عقب‌افتاده
- داشبورد مدیریتی با شاخص‌های کلیدی و تجمیع مالی
- جست‌وجو، فیلتر، مرتب‌سازی و صفحه‌بندی
- خروجی CSV فارسی سازگار با Excel
- رابط حرفه‌ای RTL، واکنش‌گرا و بدون وابستگی به CDN
- پنل مدیریت شخصی‌سازی‌شده Django Admin
- داده نمونه تکرارپذیر و ۲۳ تست خودکار
- تنظیمات محیطی، هدرهای امنیتی و راهنمای استقرار

## اجرای سریع در ویندوز

ساده‌ترین راه، اجرای فایل `run_windows.bat` است. این فایل محیط مجازی را می‌سازد، وابستگی‌ها را نصب می‌کند، دیتابیس را آماده می‌کند و سرور را بالا می‌آورد.

روش دستی:

```powershell
python -m venv .venv
.\.venv\Scripts\activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

سپس مرورگر را روی `http://127.0.0.1:8000/` باز کنید.

حساب نمونه‌ای که فرمان `seed_demo` می‌سازد:

- نام کاربری: `demo`
- رمز عبور: `Demo12345!`

این حساب فقط برای محیط آموزشی است. برای استفاده واقعی، رمز را فوراً عوض کنید.

## اجرای سریع در Linux یا macOS

```bash
chmod +x run_linux_mac.sh
./run_linux_mac.sh
```

یا همان مراحل دستی را با `python3` و فعال‌سازی `.venv/bin/activate` اجرا کنید.

## فرمان‌های مهم

```bash
# ساخت مدیر سامانه
python manage.py createsuperuser

# اجرای تست‌ها
python manage.py test

# بررسی تنظیمات و ایرادهای رایج
python manage.py check

# بررسی آماده‌بودن تنظیمات برای انتشار
DJANGO_DEBUG=false python manage.py check --deploy

# بازنشانی رمز کاربر نمونه در صورت نیاز
python manage.py seed_demo --reset-password --password "NewStrongPassword"
```

## تنظیم متغیرهای محیطی

برای توسعه، پروژه با مقدارهای امنِ مخصوص محیط محلی اجرا می‌شود. برای تنظیم دلخواه، `.env.example` را با نام `.env` کپی و مقدارها را تغییر دهید:

```text
DJANGO_SECRET_KEY=a-long-random-value
DJANGO_DEBUG=false
DJANGO_ALLOWED_HOSTS=crm.example.com
DJANGO_CSRF_TRUSTED_ORIGINS=https://crm.example.com
```

فایل `.env` در `.gitignore` قرار دارد و نباید وارد Git شود.
