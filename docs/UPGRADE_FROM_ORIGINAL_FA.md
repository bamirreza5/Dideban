# ارتقا از فایل اولیه بدون حذف حساب کاربری

پایگاه داده فایل پیوست‌شده یک حساب کاربری داشت و جدول‌های مشتری و پروژه آن خالی بودند. Migration نسخه حرفه‌ای روی یک کپی همان دیتابیس آزمایش شده و حساب موجود پس از ارتقا حفظ شده است.

## روش پیشنهادی

1. از پوشه و `db.sqlite3` نسخه پشتیبان بگیرید.
2. نسخه حرفه‌ای را در یک پوشه جدا Extract کنید.
3. فایل `db.sqlite3` نسخه قدیمی را داخل پوشه نسخه حرفه‌ای کپی کنید.
4. محیط مجازی و وابستگی‌ها را آماده کنید.
5. Migration را اجرا کنید.

ویندوز:

```powershell
python -m venv .venv
.\.venv\Scripts\activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py check
python manage.py runserver
```

## نکته مهم درباره داده نمونه

اگر می‌خواهید فقط با همان حساب قبلی کار کنید، `seed_demo` را اجرا نکنید. این فرمان کاربر جداگانه `demo` و داده‌های آموزشی می‌سازد.

## اگر رمز حساب قبلی را به یاد ندارید

```bash
python manage.py changepassword USERNAME
```

به‌جای `USERNAME` نام کاربری واقعی را وارد کنید.

## بازگشت اضطراری

اگر در ارتقا مشکلی دیدید:

1. برنامه را متوقف کنید.
2. پوشه ارتقایافته را کنار بگذارید؛ روی آن بازنویسی انجام ندهید.
3. نسخه پشتیبان کامل پوشه قدیمی را برگردانید.
4. متن کامل خطا و خروجی `python manage.py showmigrations` را بررسی کنید.

هیچ‌وقت برای حل مشکل Migration، فایل دیتابیس واقعی را بدون Backup حذف نکنید.
